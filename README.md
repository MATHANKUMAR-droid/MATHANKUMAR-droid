### Featured Projects

#### 🧠 [Mental Health Chatbot](https://github.com/MATHANKUMAR-droid/mental-health-chatbot)
Conversational agent fine-tuned for empathetic, context-aware responses to mental health queries. Built on a transformer-based backbone with intent classification and a safety fallback layer.
- Achieved **84% intent classification accuracy** on a custom-labeled dataset of 3,200 utterances
- Integrated guardrails to detect crisis-level inputs and redirect to professional resources
- `Python` · `HuggingFace Transformers` · `FastAPI` · `FAISS`

#### 🔍 [RAG Code Assistant](https://github.com/MATHANKUMAR-droid/rag-code-assistant)
A developer Q&A tool that retrieves context from local codebases and feeds it to an LLM for grounded answers — no hallucinated APIs.
- Reduced irrelevant responses by **~60%** vs. a baseline zero-shot GPT prompt on the same queries
- Supports multi-file ingestion, chunking strategies, and a simple CLI interface
- `LangChain` · `ChromaDB` · `OpenAI API` · `Python`

#### 🎙️ [Voice Assistant](https://github.com/MATHANKUMAR-droid/voice-assistant)
Real-time voice command system with speech-to-text, intent routing, and text-to-speech response.
- Processes and responds to commands in under **1.2 seconds** on average hardware
- Handles 15+ command categories with a custom routing layer
- `Python` · `SpeechRecognition` · `pyttsx3` · `Whisper`

#### 📊 [Business Analytics Dashboards](https://github.com/MATHANKUMAR-droid/analytics-dashboards)
End-to-end BI dashboards built for sales and operations data — from raw SQL queries to published Power BI reports.
- Automated a reporting workflow that previously took **3 hours/week** of manual Excel work
- Includes dynamic slicers, DAX measures, and a data cleaning pipeline in Pandas
- `Power BI` · `SQL` · `Pandas` · `DAX`
